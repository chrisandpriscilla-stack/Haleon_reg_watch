# GHG Protocol — Scope 2 Guidance revision (snapshot 2026-08-28)

- First public consultation ran Oct 2025–31 Jan 2026 (1,000+ submissions). Proposals: more time-specific (hourly) emission factors for both methods, tighter geographic/deliverability boundaries for market-based instruments, retained dual reporting (location- + market-based), legacy clause for existing contracts.
- No revised Scope 2 draft has been published since. A planned "second consultation" on Scope 2/Scope 3 interactions and steam/heat/cooling has NOT run as a standalone.
- **Material change (July 2026):** GHGP announced the Scope 2 Guidance will be folded into a single **Consolidated Corporate Standard** developed with ISO (see ghgp-market-instruments.md). Consolidated draft for public consultation now expected **Q2 2027**; final standard thereafter. This effectively supersedes the separate Scope 2 second-consultation timeline flagged in the 5 June baseline.
